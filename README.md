# Kisi Berkelanjutan Typesetter (`kisiTypesetter`)

Generic Plugin untuk **OJS 3.5** (kompatibel juga dengan OJS 3.4) yang dirancang untuk produksi rutin **edisi berjalan maupun arsip** jurnal **_Kisi Berkelanjutan: Sains Medis dan Kesehatan_** (E-ISSN: `3062-9063`, PT Karya Inovasi Berkelanjutan).
